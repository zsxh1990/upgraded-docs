# 机器人模拟仿真通用技术规范

**版本**: V1.0
**发布**: 2026-03-15
**适用范围**: 所有机器人模拟仿真项目

## 1. 仿真模型要求

### 1.1 模型格式
- 机器人本体模型: `.stp` 或 `.step` 格式
- 工装夹具模型: `.step` 或 `.iges` 格式
- 周边设备模型: `.step` 或 `.3dxml` 格式

### 1.2 模型精度
- 运动部件公差: ±0.05mm
- 静态部件公差: ±0.1mm
- 碰撞体简化: 保留主要轮廓，去除R角小于2mm的特征

### 1.3 坐标系要求
- 机器人基座标系: 与大地坐标系对齐，Z轴向上
- 工装坐标系: 与机器人基座标系的相对位置偏差 ≤ 0.5mm
- TCP 坐标系: 按照法兰盘端面中心定义

## 2. 仿真验证标准

### 2.1 可达性验证
- 目标点位覆盖率 ≥ 95%
- 奇异点规避区域标注清晰
- 关节限位检查报告

### 2.2 碰撞检测
- 静态碰撞: 0 干涉
- 动态碰撞: 间距 ≥ 5mm 安全距离
- 工具-工件间距: ≥ 2mm

### 2.3 节拍验证
- 仿真节拍与实际节拍偏差 ≤ 5%
- 加速度/减速度符合机器人规格
- 路径平滑度评估

## 3. 交付物

- 仿真项目源文件 (`*.simproj`)
- 验证报告 (PDF)
- 碰撞检测日志
- 节拍分析表 (Excel)

## 4. 参考标准

- ISO 10218: 机器人安全要求
- ISO 9283: 机器人性能测试
- 客户项目规格书
