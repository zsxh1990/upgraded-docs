# E10001-小米FANUC编程标准V1.1

E10001-小米FANUC编程标准V1.1

1. 介绍
本标准侧重于介绍FANUC机器人与PLC的编程标准，其中机器人为FANUC的R30iB系列附带Profinet通信选项
本标准为MS11及后续项目的初始适配开发，线体商及车间维修人员应透彻理解本标准，并在项目的整个阶段贯彻落实，用户必须遵守机器人规范的安装、搬运和编程指南，系统供应商有义务使用合格的机器人程序员来操作机器人系统，必须遵守本文档中描述的规范。
如有任何疑问，请联系车身ME设备组

5. IO配置
小米将提供基本 I/O 映射，其中应涵盖任何机器人应用程序所需的绝大多数 I/O。具体 I/O 配置会因应用 程序而异，但每个机器人均应满足以下要求：
        机器人应充当上级控制器的 I/O 从属机。
        将前 512 位数字输入和数字输出映射到上级控制器。
        机器人应充当其外围装置的 I/O 主机。其中包括机械臂端工具或底座工具上的任何装置。
        根据IO组态表车身机器人组态标准V1.5 对所有 I/O 进行命名，任何例外必须经小米车身设备批准。
        I/O 名称必须尽量简洁明了，且必须采用大写字母。
        I/O 现场总线仅允许采用以太网 IP  (EthernetIP) 、实时工业以太网 (Profinet) 和以太网控制自动化技术 (EtherCAT) 。

6.  程序成分
在制造环境中， 机器人经常与其他设备进行交互。进行交互需要在两台装置之间进行通信。小米已制定了机器人与外部设备进行交互的标准方法。
6.1    握手
握手是机器人与上级控制器进行通信的主要方法。可用于条件检查、请求、通知或三者任意组合。条件检 查用于询问上级控制器是否满足继续当前过程的条件。条件检查始终需要来自上级控制器的回应。请求是 对上级控制器的操作调用。请求不需要来自上级控制器的回应。当机器人需要确认请求已完成时， 请求通 常与条件检查相结合。通知用于让上级控制器知道机器人程序中发生的事情。通知不需要来自上级控制器 的回应。

8. 干涉区
两台机器人同时请求干涉区，PLC让先请求的机器人R01先进入干涉区，后请求的机器人R02需等R01退出后才能进入干涉区。多车型需使用绝对干涉区

干涉区信号由 PLC 进行中转，进入干涉区的运动轨迹路径点可以不为fine点，退出干涉区的运动轨迹路径点必须使用fine点。

9.1 程序命名规则
连接程序命名格式为：机器人编号_车型号_工艺顺序号_工艺_工作工位，工位工位例如转台AB面、料库位等，只有单个工作位可以忽略。

10. 碰撞监控等级
碰撞防护装置提供了一种高度灵敏的方法，用于检测机器人是否与物体发生碰撞，然后立即停止机器人。这有助于最大限度地降低臂端工具和机器人可能受到的损坏。碰撞保护器的灵敏度可以修改，使其灵敏度在 1-200% 之间，1% 灵敏度最低，200% 灵敏度最高。集成商/最终用户有责任确保碰撞防护装置始终处于启用状态，以保护机器人。
小米默认设置为 100%，这是机器人的标准设置。
如果需要进行某些操作，如更换工具时可能需要降低灵敏度，则可通过 TP 程序更改灵敏度值。操作完成后，灵敏度应恢复到默认值。
例如：
COL GUARD ADJUST 120     ---如果需要，还可以通过 TP 命令或碰撞保护设置页面完全关闭碰撞保护。
COL DETECT ON      ---在自动模式下启动机器人时，开启防碰撞保护装置，以保护机器人。
COL DETECT OFF     ---在自动模式下启动机器人时，关闭防碰撞保护装置。

11. 定义工具TCP和负载
工具的 TCP 可以从仿真离线中获取，但如果工具没有直接安装在机器人法兰上以减少公差，则应进行确认。如果工具 TCP 需要手动教导，则应使用 6 点 TCP 和 ZX 测量方法。如果工具 TCP 定义不正确，"MI机器人标准 "的某些功能将无法正常工作。
特殊情况手动做 TCP 时，旋转幅度要大于 90 度，橫移距离大于 50mm。固定涂胶、落地焊等要使用 RTCP。

11.2 外部/远程工具TCP定义
外部/远程工具坐标系是一种特殊类型的坐标系，并不是实际的工具坐标系。它们是技术上的基坐标系/用户坐标系， 用于确定远程或底座安装工具位置。底座安装工具的常见示例包括点焊机、涂胶喷嘴和主轴。         
      任何非搬运式机器人工具均采用外部工具中心点设置。
      外部工具中心点必须遵循与传统工具中心点相同的方向和位置惯例。

对于螺柱工具： 增加螺距，工具中心点/远程工具中心点原始位置在螺旋曲面中心。

对于涂胶：工具中心点/远程工具中心点原始位置在涂胶外径外部。
 选择外部工具中心点时，其方向必须为 Z+朝向零件，且 X+朝前
基坐标系/用户坐标系
每个机器人均有原始坐标系，所有其他坐标系均在其中定义。该坐标系通常称为通用坐标系。发那科将其称为用户坐标系。
       机器人单元中的每个夹具，包括出件站 (Take-Out station)必须有自己的基坐标系/用户坐标系。
      基坐标系/用户坐标系必须按照其操作顺序进行设置。
      电极帽修磨机基坐标系/用户坐标系
      电极帽更换机基坐标系/用户坐标系

机架基坐标系/用户坐标系定义
机架基坐标系原点设定在塔式机架的定位销上。 XY 平面与垫板平面相同。 X+朝向机架里面，Z+朝上。 顶部和底部机架需要两个单独的基坐标系。

13.2 注释
所有机器人程序应配有相应的注释， 以便于故障排除。需提供如下注释。
        在更换工具之前添加注释。注释必须包含工具的名称。
        在更换基坐标系/工件坐标系之前添加注释。注释必须包含基坐标系/工件坐标系的名称。
        在调用握手之前添加注释。注释必须包含握手编号和描述。
        在进入或退出夹具之前添加注释。注释必须包含夹具编号和夹具名称。
        对于使用空间检查的发那科机器人-在进入和退出空间之前添加注释。
        在进入或退出区域之前添加注释。注释必须包含干涉区域编号和共用该区域的机器人。
        所有 I/O 注释必须在程序中可见。
        根据工艺单对所有连接工艺点进行注释。
13.3 运动
        优化机器人序列，使其循环时间尽可能短， 且不会损坏零件或管线包。
        避免管线包摩擦机器人手腕。
        勿发出圆弧运动指令。使用近似的多个直线运动。圆弧运动指令很难重新示教。
        每个程序的第一个动作必须是 PTP/关节移动。直线运动可以根据当前位置， 将 J4 和J6 定位在与所教位置不同的位置。
        进行编程，尽可能通过连续运动避免发生急跳动作。
        在起始位置或公共位置使用位置寄存器时，使用锁定位置寄存器和解锁位置寄存器，以防止移动作为精细的动作执行。
        使用公共位置运动到一条路径或另一条路径时，公共位置不干扰任何路径(公共位置是在通往任何路径途中) 。公共位置必须设置全局/位置寄存器。
        底座伺服焊枪必须能够在不进行点焊过程的同时随时运行后台电极帽修磨程序。
       底座伺服焊枪在不运行焊接程序或后台电极帽修磨程序时，必须有 10mm 的开口， 以避免不必要的手动更换电极帽。
        当夹具准备运行时，在进入夹具之前，当可能接近零件/机器人本体时， 需要设待命位置，从而提高循环时间。
  在对点焊运动点进行编程时，将焊枪缩回位置设置为最小开口， 以优化循环时间， 但不小于 10mm ，这是获得适当焊枪力所需的最小开口。
  在对自冲铆接运动点进行编程时，将焊枪缩回位置设置为最小开口，以优化循环时间。
  在进入任何安全监控空间之前，机器人必须调用进入握手请求， 以确认该空间可以进入。
  对于配有非移动式应用程序(如点焊、自冲铆接和螺柱焊接)的发那科机器人，勿在运动指令中添加 RTCP 选项，因为它会减慢机器人的运动。
  勿将 Base[0]/UFrame[0]用于夹具， 因为 Base[0]无法修改。诸如维护、手动换帽、清洗等
  料库自抓程序可以使用 Base[0]/UFrame[0] ，因为这个流程没有用到夹具。
  无需在每次焊接前/后添加偏移点；将点焊近似距离设置为 5mm。在进入或离开工艺零件时，使用附加点以避免碰撞。

  确保起始位置是唯一的(不能在同一坐标上示教其他位置)，并且始终是安全位置 -有效负载设置必须正确。
工艺点如FDS，外观焊点（由产品输出的，在总装装完车，仍然外露的焊点，是外观焊点），SPR等需使用fine点
