# 机器人BASE测量及计算规范

机器人BASE测量及计算规范

1  范围

    本标准规定了基于线体设备精确安装，测量和计算机器人BASE及外部固定工具TCP实际值的技术要求。 适用于小米汽车所有需要进行机器人离线程序导入的自动工位。 

2  术语和定义

2.1 CA

    Cell Alignment，指精确安装调试线体设备，确保设备安装精度在规定精度范围内，并通过测量计算得出机器人BASE及固定工具TCP的一整套流程。

2.2 CA1

    CA1指明确线体工装、设备精确安装方式，保证安装后的实际位置较理论值（仿真）在允许误差范围内的一整套操作流程。 

2.3 CA2

    CA2 指测量和计算线体机器人BASE及外部固定工具TCP实际值，并计算实际值与理论值（仿真）偏差的一整套操作流程。 

3 设备准备

  设备应满足如下规定： 

a）设备选用高精度激光跟踪仪，单站测量半径≥20m； 

b) 仪器设备应在检校合格有效期内使用，并提供设备检校报告； 

c) 激光跟踪仪精度≤20µm+6µm/m ，重复精度10µm+4µm/m ，测距误差≤20µm 。 

4  作业流程

4.1 测量及计算固定机器人 BASE

    1）通过测量主夹具 BASE 面上基准孔，转换测量仪器坐标系为车身坐标系，如下图所示。

    2）粘贴测量靶座至机器人工具上（机器人运动中，靶座与工具TCP无相对移动，且靶球位置尽量靠近TCP的位置）。

    3）机器人移动 15～20 个测量点（使用 Tool0 和 Base0 示教，不得出现仅绕工具 TCP z 向旋转的情况）， 测量点分散于夹具的工作范围内，分别记录并输出机器人坐标值（相对机器人 Base0）、测量靶球坐标值 （相对夹具车身坐标系），如下图所示。 

机器人坐标值、靶球测量值导入“专业计算软件”，计算得出机器人Base0相对工装夹具车身坐标系的实际值，并比较与其理论值的偏差，若偏差值≤5mm，则说明理论机器人BASE满足精度要求，若偏差值≥5mm，则需按下图所示方案进行整改。 

    5）如机器人涉及同类工艺操作（如切换枪焊接）下的多工具切换，以安装最重的一套工具计算为准， 不同类工艺要求的（如纯搬运和焊接切换），以参与产品工艺制造的工具（焊枪）计算为准。 

4.2 测量及计算七轴机器人 BASE

    1）情形1：工艺过程集中在轨道运动的某个位置上。 

    在工作主夹具范围内编制至少10个不同的伸展姿态。然后机器人停在七轴上某一个位置，在该点另一个夹具或工作范围内编制另外10不同的伸展姿态，如果机器人其他工作是物料搬运类，不是工艺处理， 机器人姿态可以减少，并沿着七轴运动方向伸展。机器人运动及七轴参数必须与七轴运动同步，运行整个程序（至少15-20个姿态）并测量在这些位置靶球的值。 

    情形2：机器人工艺处理沿着七轴方向。 

    将机器人在七轴上的运动划分多段（1-1.5m 一段），在每个划分点编制至少 7 个不同的伸展姿态，每个划分点须有七轴的值，且在该点的各个姿态七轴值绝对一致。运行程序并测量在这些位置靶球的值。 

    3）行走七轴的base将成为机器人的原点，其不跟随机器运动；确认七轴马达数据已正确配置到了机器人系统中，并且与仿真系统中的数据一样。 

4.3 测量及计算外部固定工具TCP

    1）工位内，通过测量主夹具BASE面上基准孔，转换测量仪器坐标系为车身坐标系。 

    2）使用激光跟踪仪测量外部工具TCP，测得的TCP坐标值是相对于车身坐标系的。 

    3）通过机器人BASE测量及计算的方法，得出实际机器人BASE相对车身坐标系的坐标值。

    4）已知车身坐标系中的机器人实际BASE和外部工具TCP值，通过测量软件转换，可得出外部工具相对机器人实际BASE的TCP值，如下图所示。

    5）若工位中无车身坐标系时，需要在工作范围内固定的设备上创建4-5个参考孔（孔和数据需要单独文档与对应机器人的测量报告一起提供），并创建临时坐标系用于测量，转换仪器坐标系至临时坐标系，其余操作同车间坐标系情况一致。 

4.4 结果验证

 1） 验证方法：

a) 将测量出的机器人车身坐标Base和TCP值（即靶球的位置）输入机器人中； b) 使用该Base和TCP, 移动机器人至少三个位置； 

c) 测量各点位置值，比较测量系统给出的位置值和机器人示教器给出的位置值，偏差≤2mm，否则进行检查。 

 2） 原因分析

a) 测量结果验证误差太大。检查机器人控制器中当时使用的base值并确认使用了正确的TCP； 

b) TCP检查误差太大的潜在原因。机器人零点校正未做好；机器人Machine data 不正确；靶球没有固定好或安装不正确；机器人工具或工具部分部件没安装或固定好（检查TCP计算数据中的最大、最小值，差值不应该超过4mm）。 

c) Rmax太大。检查TCP数据，如果一个POSE异常超出误差，计算时将其移除（可能测量时机器人没有精确到达设定位置）；确认机器人是否正确进行零位校准；机器人可能故障；机器人绝对精度没有激活。
